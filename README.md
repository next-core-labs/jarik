# جارك — Jarak

Property management platform and public real-estate marketplace (Saudi Arabia).

- **Stack:** TanStack Start (React 19) · Tailwind v4 · Supabase (Postgres, Auth, Storage) · Cloudflare Workers
- **Run locally:** `npm install` → `npm run dev` → http://localhost:8080
- **Deploy and setup:** see [DEPLOY.md](DEPLOY.md)
- **Database changes:** `supabase/migrations/` → `npm run db:push` → `npm run db:types`

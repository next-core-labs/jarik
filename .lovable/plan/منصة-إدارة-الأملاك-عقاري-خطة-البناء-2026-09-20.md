# منصة إدارة الأملاك (عقاري) — خطة البناء

نظام واحد يجمع: إدارة الأملاك، العملاء، الصفقات، التحصيل والمحاسبة، الصيانة، الفوترة الإلكترونية، والتسويق — مع مساعد ذكي يعمل بدل الموظف ولا ينتظره.

## المبدأ الأساسي
البرنامج لا يُسجّل البيانات فقط، بل ينفّذ ويُلاحق:
- إشعارات وتذكير تلقائي للمستأجر قبل وبعد استحقاق الإيجار.
- إنشاء مهمة صيانة تلقائيًا من طلب المستأجر وإسنادها لفني.
- متابعة العقود المنتهية والشواغر وتنبيه المسؤول.
- تقارير ومؤشرات تُحدّث نفسها.

## الشاشات
1. **لوحة المؤشرات** — نسبة الإشغال، الشواغر، المحصّل مقابل المستحق، المصروفات، الصيانة المفتوحة، العقود المنتهية قريبًا.
2. **الأملاك والوحدات** — عقار ← وحدات، حالة كل وحدة (مشغولة/شاغرة)، **رقم عداد الكهرباء ورقم عداد المياه** لكل وحدة مع قراءات دورية.
3. **المستأجرون والعقود** — بيانات المستأجر، مدة العقد، الإيجار، جدول الدفعات، حالة التوافق مع إيجار.
4. **التحصيل والمحاسبة** — الدفعات، المتأخرات، المصروفات، كشف حساب المالك، فواتير إلكترونية بصيغة متوافقة مع متطلبات ZATCA (رقم ضريبي، QR، تفاصيل الضريبة).
5. **الصيانة** — طلبات، إسناد لفني، حالة (جديد/جاري/منجز)، تكلفة تُرحّل للمصروفات.
6. **المبيعات والصفقات** — عملاء محتملون، مراحل الصفقة، العمولات.
7. **التسويق** — عرض الوحدات الشاغرة وصفحة عرض للوحدة قابلة للمشاركة.
8. **صفحات العملاء حسب الدور**:
   - المالك: عقاراته، إشغاله، حسابه، كشوفه.
   - المستأجر: عقده، مدفوعاته، فواتيره، طلب صيانة.
   - الفني: أعماله المسندة وتحديث حالتها.

## الأدوار
مدير النظام، موظف/محاسب، مالك، مستأجر، فني — كل دور يرى بياناته فقط.

## الذكاء الاصطناعي
- **مساعد واتساب (الطبقة الذكية)**: يفهم رسائل المستأجر بالعربي (سؤال عن رصيد، إبلاغ عن عطل، تأكيد سداد) ويحوّلها إلى إجراء داخل النظام + رد مناسب.
- ملخص ذكي للوحة المؤشرات وللمتأخرات.
- مساعد لكتابة إعلانات تسويق الوحدات.

## الجانب التقني
- Lovable Cloud للبيانات والحسابات والصلاحيات (RLS لكل دور).
- جداول: properties, units (مع electricity_meter_no, water_meter_no), meter_readings, tenants, leases, payments, invoices (حقول ZATCA), expenses, maintenance_requests, deals, owners_statements, user_roles.
- الذكاء الاصطناعي عبر Lovable AI على السيرفر.
- تكامل إيجار وواتساب: تُبنى الواجهة والمنطق الآن، ويُوصَّل رسميًا عند توفير بيانات الدخول/المفاتيح من جهتك.

## مراحل التنفيذ
1. التصميم + قاعدة البيانات + الحسابات والأدوار.
2. الأملاك/الوحدات/العدادات + المستأجرون والعقود.
3. التحصيل والمصروفات + الفوترة الإلكترونية (ZATCA).
4. الصيانة + بوابات المالك/المستأجر/الفني.
5. لوحة المؤشرات + الأتمتة والتذكيرات.
6. المبيعات والتسويق + المساعد الذكي وواتساب.

## يحتاج منك لاحقًا
- الاسم التجاري والشعار والرقم الضريبي (للفواتير).
- بيانات تكامل «إيجار» ورقم واتساب الأعمال.
